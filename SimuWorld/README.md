# SimuWorld — Engineering Simulation Studio (Prototype 0.1)

## Run the app
1. Download or clone this repository.
2. Open the `SimuWorld` folder.
3. Open `index.html` in Chrome or Edge.

No installation, server, account, or API key is required.

## Included
- Engineering dashboard
- Animated schematic of a motor driving two gears
- Adjustable motor speed, torque, gear tooth counts, and transmission efficiency
- Live output speed, torque, gear ratio, and power calculations
- Performance graph
- Saveable experiment scenarios
- Browser-local project saving
- Guided design-assistant preview
- Basic report view

## Limitations
This is an early educational prototype. It uses a simplified gear-pair model and does not simulate detailed tooth contact, friction variation, heat, vibration, bearing loads, or motor operating curves. It is not suitable for certifying or validating a physical machine design.

The design assistant is a local guided preview, not a connected AI service. Projects are stored in the current browser's local storage; there are no cloud accounts or cross-device sync yet.
